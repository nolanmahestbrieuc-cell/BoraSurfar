# BoraSurfar

Site vitrine pour **BoraSurfar**, une école et communauté de surf. HTML / CSS / JS statique, sans dépendance ni framework — aucun build nécessaire.

## Structure

```
.
├── index.html
├── assets/
│   ├── css/style.css
│   └── js/main.js
└── README.md
```

## Lancer en local

Ouvrir simplement `index.html` dans un navigateur, ou servir le dossier :

```bash
python3 -m http.server 8000
```

puis aller sur `http://localhost:8000`.

## Sections

- **Hero** — accroche animée avec vagues SVG
- **École** — arguments clés (niveaux, spots, communauté, éco-responsabilité)
- **Spots** — présentation de 3 spots de surf
- **Cours** — formules et tarifs
- **Galerie** — aperçu visuel
- **Avis** — carrousel de témoignages
- **Contact** — formulaire (démo, sans backend)
